# fast-laya-plugin Claude Code mod

This plugin uses Claude Code function hooks to replace a compaction with the
original messages, minus the tool calls and tool results a local Laya model
judged no longer needed. `hooks/fast-laya.ts` is a thin adapter. It reads the
plugin options, hands `session.compact` transcripts to the library in `src/`
(the plugin folder is the repository root, so the hook imports it directly)
and maps the result back onto session messages. User and assistant text is
never touched.

For every tool call outside the pinned first and newest messages, the hook
sends one request to `laya-serve` through `$.http.fetch`. The state of each
request describes only that call: the goal, the nearest messages around it,
its input, a short preview of its output and the later calls, fitted into
`maxStateTokens`. The question is a three-way `choice` (`keep`, `truncate`,
`drop`). An item is kept when its probability reaches `keepThreshold`. A
dropped result is truncated to its first `truncateHeadChars` characters plus
a one-line note. A dropped call disappears with its result. See the root
README for the details and for why the state is per call.

The checked-in type reference was generated by Claude Code **2.1.274**.

## Setup

1. Install `laya-serve` (Python 3.10 or newer, through uv). The plugin starts
   it by itself when a session starts (see [Automatic start](#automatic-start)):

   ```sh
   uv tool install "laya[serve]"
   ```

2. Enable function hooks wherever Claude Code runs.

   bash: `export CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`

   PowerShell: `$env:CLAUDE_CODE_ENABLE_FUNCTION_HOOKS = "1"` (or
   `[Environment]::SetEnvironmentVariable("CLAUDE_CODE_ENABLE_FUNCTION_HOOKS", "1", "User")`
   to keep it)

3. Install the plugin inside Claude Code:

   ```
   /plugin marketplace add Chamoouske/fast-laya-plugin
   /plugin install fast-laya-plugin@fast-laya-plugin
   ```

For local development, start Claude Code from the repository root with
`claude --plugin-dir .` and the flag set.

## Configuration

The plugin declares these `userConfig` values in
`.claude-plugin/plugin.json`:

| Option | Default |
| --- | ---: |
| `baseUrl` | `http://127.0.0.1:8000/v1/systemone` |
| `model` | `laya` |
| `keepThreshold` | `0.5` |
| `preserveRecentMessages` | `6` |
| `compactAtPercent` | `60` |
| `minReductionRatio` | `0.25` |
| `maxStateTokens` | `400` |
| `truncateHeadChars` | `300` |
| `concurrency` | `4` |
| `autoStart` | `true` |
| `layaServeCommand` | `laya-serve` |
| `startupTimeoutSeconds` | `90` |

No API key is needed. Every option except `baseUrl`, `model`,
`compactAtPercent`, `minReductionRatio` and the three start options is
passed straight to the library.

## Automatic start

`hooks/laya-launch.ts` keeps `laya-serve` running. On `session.start` it
checks `/health` and, when the endpoint is local and silent, starts
`laya-serve` detached through `$.process.run` (`Start-Process -WindowStyle
Hidden` on Windows, `nohup … &` elsewhere), with `LAYA_HOST`, `LAYA_PORT` and
`LAYA_MODELS` derived from `baseUrl` and `model`. It does not wait for the
model to load. `session.compact` runs the same check, then waits up to
`startupTimeoutSeconds` for `/health` before asking Laya; a timeout falls back
like any other error. A launch is not repeated within that window, so a
server still loading is not started twice. `autoStart: false` or a remote
`baseUrl` turns all of this off.
For `laya-multilingual` (1024 tokens), raise `maxStateTokens` to about 900.

## Fallback

If `laya-serve` is unreachable, returns an error (for example 503 above
`LAYA_MAX_CONCURRENT`), returns a malformed answer, or the estimated reduction
is below `minReductionRatio`, the hook logs a fallback and calls `next(event)`,
so Claude Code's built-in compaction runs. The outcome is shown as a toast and
logged with the reduction, the counts per reason, the number of requests, the
largest state, and how many states Laya reported as cut. A per-call
`decisions:` line with both keep probabilities is logged for diagnosis. The
`turn.complete` hook requests compaction when `context.percent` reaches
`compactAtPercent`, with an in-flight guard.

## Scope and caveat

Function hooks are early access and may change between Claude Code releases.
This mod uses the generated declarations from 2.1.274 in
`types/claude-code.d.ts`; regenerate and review that file after a Claude
Code upgrade.
